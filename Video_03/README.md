# Video 3 — Information Entropy of m-Blocks

Extends the single-character entropy of [Video 2](../Video_02/) to **blocks of $m$ characters**, showing how block entropy $H_m$ and the entropy rate behave as the block length grows.

### 📺 [Watch on YouTube](https://youtu.be/6Ijdrrp0DeQ)

## Contents

- **Information_Entropy_of_m_blocks.ipynb** — the interactive notebook
- **notes.txt** — transcript of the lecture with timestamps
- **Screenshots/** — frames captured from the lecture video

## Running Locally

From the repo root:

```bash
pip install -r requirements.txt
jupyter notebook Video_03/Information_Entropy_of_m_blocks.ipynb
```
